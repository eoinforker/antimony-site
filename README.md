# Antimony

The public site of Antimony, makers of Orbe. Plain static HTML, served by GitHub Pages from the `main` branch root. No build step.

- `index.html`: the home page.
- `v/`: ten design directions for review (`v/index.html` lists them). They are marked `noindex`.
- `assets/`: the identity (mark, wordmark, lockups, favicon), the crystal art and the fonts.

## Fonts

Schibsted Grotesk, Commit Mono and Newsreader are SIL Open Font License 1.1; the licence files sit beside them in `assets/fonts/`.

## Hosting

Enable Pages under Settings, Pages, Deploy from a branch, `main`, root. The site is then served at `eoinforker.github.io/antimony-site`. For a custom domain, add a `CNAME` file holding the bare domain and set the same domain in Settings, Pages.
